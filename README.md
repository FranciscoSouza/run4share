# run4share

Turn workout stats into shareable images. Flutter app for Android and iOS.

## Getting started

```sh
bash tool/setup.sh   # fonts, platform folders, packages, l10n, analyze, test
flutter run          # with an Android phone plugged in
```

Design artboards live in `design/`; project notes for contributors are in
`CLAUDE.md`. Strava secrets never go in this repository.
